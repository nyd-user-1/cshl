**P3 — new rows (after P1 done + the same dependency as P2).**
From the P1 JSONL, a record is NEW when: its arXiv id is not in `nsr.arxiv_id`, AND its published DOI (if any) is not in `nsr.doi` (lowercased match), AND its arXiv DOI `10.48550/arXiv.<id>` is not in `nsr.doi`.
- Insert new rows: `key_number = '10.48550/arXiv.<id>'`, `doi` same, `pub_year` from the arXiv id/date, `title`, `authors` ("; "-joined), `abstract` (full), `arxiv_id`, `reference_type='PREPRINT'`, `is_primary=true`, `is_nsr=false`, `raw={source:'arxiv-oai', set, categories, journal_ref, ...}`. `ON CONFLICT (key_number) DO NOTHING`.
- Stage + insert in ≤25k-row psql chunks. Report inserted count and the new `SELECT is_nsr, count(*) FROM nsr GROUP BY 1`.
