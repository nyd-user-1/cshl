# The room map

Generated by `scripts/classify/build-room-map.py` from a corpus of **433,449** papers.
Room ceiling **10,000** — **provisional**: D9 (LANE-CURVE) has not run, so this is the brief's placeholder, not a measured ceiling. Re-run this script with `--max-room N` once `docs/HAYSTACK-CURVE.md` exists.

A **room** is a scoped haystack a subject agent searches. The bet is that our stack wins inside
small rooms (see `docs/BEDROCK-KB-BAKEOFF.md`), so every room must come in under the ceiling.
This is **not** a query-time router — the user's navigation choice is the router.

### What the predicted labels bought

Both configurations place every paper, so "papers without a room" is zero either way and
says nothing. The real gain is **which axis** a paper is placed on: a room split by MeSH
subtree is a topic a researcher can choose; a room split by year is a filing cabinet.

| axis | papers, observed MeSH only | papers, + predicted | change |
|---|---|---|---|
| `mesh` | 140,664 | 282,801 | +142,137 |
| `category` | 95,142 | 95,142 | +0 |
| `year` | 94,930 | 47,287 | -47,643 |
| `no-mesh-facet` | 102,205 | 7,711 | -94,494 |
| `residual` | 508 | 508 | +0 |

Rooms rose 170 → 252: papers that previously fell into a few
huge undifferentiated year buckets now separate into named topics.

## Calibration — predicted labels are not observed labels

261,768 papers carry a **predicted** MeSH tag from `knn-bge-m3-k15` rather than an
NLM-assigned one. They live in a separate table (`preprint_mesh_predicted`), every row carries
its probability and the model id, and observed MeSH is never overwritten.

**The labeller is kNN propagation over stock bge-m3 embeddings, NOT cshl-MESH-tagger.**
The tagger was trained, scored, and lost to that baseline on every ranking metric
(P@5 58.68 vs 63.39, R@15 52.66 vs 61.82 on the full held-out test split), so using it here
would have meant labelling the corpus with the arm measured to be worse. Both arms are
loaded in `preprint_mesh_predicted`, distinguished by `model`, so the choice is reversible
and auditable. The `predicted` column
below is how many of a room's members were placed using a predicted label — a room at 100% is a
room whose very existence is a model's opinion, and should be read that way.

## Papers without a room: **zero**

Every paper in the corpus is in exactly one room. Rooms are a partition, not an overlay —
so this count is meaningful rather than an artefact of double-counting.
